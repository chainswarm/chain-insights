# Phase 4 — UI Design Contract

> Visual and interaction contract for the money flow visualization phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Rendering context:** Server-side D3.js rendered via jsdom into self-contained HTML files served by the local Hono server. No React, no component library, no build-time CSS framework. All styles are inline CSS within the HTML document.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | none (pure D3.js v7 + inline HTML/CSS/JS) |
| Icon library | none (entity types encoded as SVG shapes) |
| Font | `system-ui, -apple-system, "Segoe UI", Roboto, sans-serif` |

**Rationale:** Self-contained HTML cannot reference external font files. System font stack ensures consistent rendering across platforms with zero network requests.

## Typography

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 13px | 400 (regular) | 1.5 | Tooltip text, legend descriptions, edge labels |
| Label | 11px | 600 (semibold) | 1.3 | Node labels, axis labels, "X more hidden" indicator |

## Entity Shapes — SVG Specification

Each entity type has a distinct SVG shape. All shapes are centered at (0,0) for D3 node positioning.

| Entity | Shape | SVG Path (r=radius) | Default Radius |
|--------|-------|---------------------|----------------|
| EOA | Circle | `<circle r="{r}"/>` | 20px |
| Contract | Diamond | `<polygon points="0,-{r} {r},0 0,{r} -{r},0"/>` | 22px |
| Exchange | Hexagon | Regular hexagon, 6 equidistant points at radius `r` | 22px |
| Mixer | Triangle | `<polygon points="0,-{r} {r*0.866},{r*0.5} -{r*0.866},{r*0.5}"/>` | 22px |

**Node size scaling:** Base radius is 20px. Scale linearly by total transaction volume passing through the node, clamped to range [16px, 36px]. Formula: `clamp(16, 20 + log2(volume / medianVolume) * 4, 36)`.

**Risk border:** 3px stroke width using the risk level color. Nodes with unknown risk use `--risk-unknown` gray border.

## Graph Interaction Contract

### Force-Directed Layout

| Parameter | Value | Rationale |
|-----------|-------|-----------|
| Charge strength | -300 | Moderate repulsion prevents overlap without excessive spread |
| Link distance | 120px | Enough room for edge labels between nodes |
| Collision radius | node radius + 8px | Prevents node overlap with breathing room |
| Center force | (viewportWidth/2, viewportHeight/2) | Keeps graph centered in viewport |
| Alpha decay | 0.02 | Slower cooling for smoother settling |
| Velocity decay | 0.4 | Moderate damping for responsive drag |

### Tree Layout

| Parameter | Value |
|-----------|-------|
| Node separation | 1.5 (d3.tree().separation) |
| Depth spacing | 180px between levels |
| Orientation | Top-to-bottom (root = source wallet) |

### Pan and Zoom

| Behavior | Specification |
|----------|---------------|
| Zoom range | [0.1, 8] scale extent |
| Zoom input | Mouse wheel / trackpad pinch |
| Pan input | Click-drag on canvas (not on nodes) |
| Initial fit | Auto-fit all nodes with 32px padding on load |
| Zoom transition | 250ms ease-in-out on programmatic zoom |

### Node Drag (Force-Directed Only)

| Behavior | Specification |
|----------|---------------|
| Drag start | Fix node position, raise alphaTarget to 0.3 |
| Dragging | Update node fx/fy to cursor position |
| Drag end | Release fx/fy (node rejoins simulation) |
| Cursor | `grab` on hover, `grabbing` while dragging |

### Layout Toggle

| Property | Value |
|----------|-------|
| Control | Single toggle button in top-left control bar |
| Labels | "Force" / "Tree" |
| Active state | Accent color (`#3b82f6`) background, white text |
| Inactive state | Secondary (`#1a1d27`) background, secondary text color |
| Transition | 500ms crossfade: fade out old positions, recompute, fade in new positions |

## Edge (Link) Specification

| Property | Value |
|----------|-------|
| Default stroke | `#475569` at 1px |
| Thickness scale | Linear from 1px to 6px based on transaction value (min to max in dataset) |
| Hover stroke | `#e2e8f0` (primary text color) |

## HTML Document Structure

The self-contained HTML file follows this structure:

```
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>{Viz Title}</title>
  <style>/* All CSS inline — see CSS contract below */</style>
</head>
<body>
  <div id="viz-root">
    <div id="truncation-banner"><!-- if >100 nodes --></div>
    <div id="control-bar">
      <div id="layout-toggle"><!-- Force / Tree buttons --></div>
      <button id="zoom-reset"><!-- Fit to view --></button>
    </div>
    <svg id="graph"><!-- D3 renders here --></svg>
    <div id="legend-panel"><!-- Collapsible legend --></div>
    <div id="tooltip"><!-- Positioned absolutely --></div>
  </div>
  <script>/* D3.js v7 minified inline */</script>
  <script>/* Graph data as JSON literal */</script>
  <script>/* Visualization logic */</script>
</body>
</html>
```
