Also export a `truncateGraph` function:
```typescript
const MAX_NODES = 100

export function truncateGraph(data: GraphData): GraphData {
  if (data.nodes.length <= MAX_NODES) return data
  const sorted = [...data.nodes].sort((a, b) => (b.totalIn + b.totalOut) - (a.totalIn + a.totalOut))
  const kept = sorted.slice(0, MAX_NODES)
  const keptIds = new Set(kept.map(n => n.id))
  const filteredEdges = data.edges.filter(e => keptIds.has(e.source) && keptIds.has(e.target))
  return {
    nodes: kept,
    edges: filteredEdges,
    metadata: {
      ...data.metadata,
      truncated: true,
      totalNodes: data.nodes.length,
      hiddenNodes: data.nodes.length - MAX_NODES,
    },
  }
}
```

**Step 3: Create `src/viz/templates/viz-logic.ts`.**
Export `buildVizLogic(): string` returning a template literal containing the client-side D3 JavaScript. This code runs in the browser.

The viz-logic must implement all of these (per CONTEXT.md locked decisions + UI-SPEC):

**Force-directed layout** (default):
- `d3.forceSimulation(nodes)` with `.force('charge', d3.forceManyBody().strength(-300))`, `.force('link', d3.forceLink(links).id(d => d.id).distance(120))`, `.force('center', d3.forceCenter(width/2, height/2))`, `.force('collision', d3.forceCollide().radius(d => d.radius + 8))`, `.alphaDecay(0.02)`, `.velocityDecay(0.4)`.
- On tick: update link x1/y1/x2/y2 and node group transform.

**Entity shapes** (from UI-SPEC):
- EOA = `<circle>` (fill `#6366f1`), Contract = diamond path, Exchange = hexagon path, Mixer = triangle path.
- Shape function: `entityShape(type, radius)` returns null for circle (use `<circle>`), or SVG path string for others.
- Node groups use `selection.join()` (D3 v7 pattern, NOT enter/exit).
- Each node rendered as `<g class="node-group">` containing either `<circle>` or `<path>` for the shape, plus a `<text>` label (truncated address: first 6 + last 4 chars), plus a `<title>` element for a11y.

**Node size scaling** (from UI-SPEC):
- `nodeRadius(volume, medianVolume) = clamp(16, 20 + log2(volume / medianVolume) * 4, 36)`.
- Volume = totalIn + totalOut. Median computed from all nodes.

**Risk borders**:
- 3px stroke on node shape using risk color. Colors: low=#22c55e, medium=#eab308, high=#f97316, critical=#ef4444, unknown=#6b7280.

**Edge rendering**:
- `<line>` elements for force layout, `<path>` for tree layout.
- Thickness: `edgeWidth(value, minVal, maxVal) = 1 + ((value - minVal) / (maxVal - minVal)) * 5` (1px to 6px). If minVal === maxVal, return 2.
- Default stroke `#475569`. Hover stroke `#e2e8f0`.
- SVG `<marker>` arrow at end, 8px triangle, same color as edge.
- Multiple edges between same pair: offset by 8px parallel.

**Zoom and pan** (from UI-SPEC):
- `d3.zoom().scaleExtent([0.1, 8])` applied to SVG, transforms a `<g>` container.
- Auto-fit on load: compute bounding box, scale to fit with 32px padding, 250ms transition.
- Zoom reset button: triggers `fitToView()` function.

**Node drag** (force layout only, from UI-SPEC):
- `d3.drag()` on node groups. On start: `d.fx = d.x; d.fy = d.y; simulation.alphaTarget(0.3).restart()`. On drag: `d.fx = event.x; d.fy = event.y`. On end: release fx/fy, `simulation.alphaTarget(0)`.

**Layout toggle** (from CONTEXT.md):
- Two buttons in control-bar: "Force" and "Tree". Active one gets `.active` class.
- Switching to Tree: stop simulation, store force positions as `node.forceX/forceY`, build hierarchy with virtual root connecting source nodes, run `d3.tree().size([width, height - 100]).separation(() => 1.5)`, animate nodes to tree positions over 500ms, redraw links as curves using `d3.linkVertical()`.
- Switching to Force: restore positions from `node.forceX/forceY`, restart simulation, redraw links as straight lines. Re-enable drag.
- Detect cycles for tree: DFS traversal, break cycles by keeping first occurrence. Show console.warn when cycles detected.

**Tooltips** (from UI-SPEC):
- Node tooltip on hover (200ms delay): shows entity type, address (truncated), risk badge, totalIn, totalOut, txCount, firstSeen, lastSeen.
- Edge tooltip on hover: shows from, to (truncated addresses), amount, txHash (truncated), blockNumber, timestamp.

**Legend panel** (from UI-SPEC):

```typescript
export async function generateVisualization(opts: {
  caseId?: string
  dataFile?: string
}): Promise<{ vizId: string; htmlPath: string }> {
  let rawData: unknown

  if (opts.dataFile) {
    const content = await readFile(opts.dataFile, 'utf-8')
    try {
      rawData = JSON.parse(content)
    } catch {
      throw new Error('Invalid transaction data. The input file must contain a JSON array of transaction objects with `from`, `to`, and `value` fields.')
    }
  } else if (opts.caseId) {
    // Case-based extraction -- implemented in Plan 02
    throw new Error('Case not found. Run `chain-insights case list` to see available cases.')
  } else {
    throw new Error('Provide either a case ID or --data <file.json>')
  }

  // Validate and parse
  const parsed = GraphData.parse(rawData)
  const data = truncateGraph(parsed)

  // Generate viz ID
  const vizId = opts.caseId
    ? `${opts.caseId}_${Date.now()}`
    : `adhoc_${Date.now()}`

  // Title
  const title = data.metadata.caseId
    ? `${data.metadata.caseId} - Money Flow`
    : 'Ad-hoc Visualization'

  // Generate HTML and write to disk
  const html = generateHtml(data, title)
  const htmlPath = await writeVizHtml(vizId, html)

  return { vizId, htmlPath }
}
```

```typescript
import { Hono } from 'hono'
import { readFile } from 'node:fs/promises'
import path from 'node:path'
import os from 'node:os'

export function createApp(): Hono {
  const app = new Hono()

  app.get('/health', (c) => c.json({ ok: true, ts: Date.now() }))

  app.get('/status', async (c) => {
    const { healthCheck } = await import('../db/index.js')
    const db = await healthCheck()
    return c.json({
      database: db.ok ? 'healthy' : 'error',
      server: 'running',
    })
  })

  app.get('/viz/:id', async (c) => {
    const id = c.req.param('id')
    if (!/^[a-zA-Z0-9_-]+$/.test(id)) {
      return c.json({ error: 'Invalid visualization ID' }, 400)
    }
    const vizDir = path.join(os.homedir(), '.chain-insights', 'viz')
    const filePath = path.join(vizDir, `${id}.html`)
    try {
      const html = await readFile(filePath, 'utf-8')
      return c.html(html)
    } catch {
      return c.json({ error: 'Visualization not found' }, 404)
    }
  })

  app.onError((err, c) => {
    console.error(err)
    return c.json({ error: 'Internal server error' }, 500)
  })

  return app
}
```
