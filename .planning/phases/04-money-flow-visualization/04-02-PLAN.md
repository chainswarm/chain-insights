**Step 2: Create `src/viz/data-extractor.ts`.**

Follow the `EvidenceStore` pattern: export object literal with methods, use `readFile`/`readdir` from `node:fs/promises`, `path` and `os` for directory resolution.

```typescript
import { readFile, readdir } from 'node:fs/promises'
import path from 'node:path'
import os from 'node:os'
import { GraphData, GraphNode, GraphEdge } from './graph-model.js'
import { parseFrontmatter } from '../cases/frontmatter.js'

function caseDir(caseId: string): string {
  return path.join(os.homedir(), '.chain-insights', 'cases', caseId)
}
```

**`parseEvidenceJson(markdown: string): unknown[]`** -- Extracts JSON from code blocks:
1. Find all ```` ```json ... ``` ```` blocks using regex: `` /```json\s*\n([\s\S]*?)```/g ``
2. For each block, `JSON.parse()` the content.
3. If the parsed result is an array, push all items. If it's an object with `nodes` and `edges`, treat as full GraphData.
4. Return array of parsed items. Return empty array if no JSON blocks found.

**`extractGraphFromJson(input: unknown): GraphData`** -- Handles two input formats:
1. If input has `nodes` and `edges` properties, parse with `GraphData.parse(input)` and return.
2. If input is an array, treat each item as `{ from, to, value, txHash?, blockNumber?, timestamp? }`:
   - Collect unique addresses from `from` and `to` fields.
   - Create GraphNode for each unique address (id = address, entityType = 'unknown', riskLevel = 'unknown').
   - Compute totalIn, totalOut, txCount for each node from the edges.
   - Create GraphEdge for each item (source = from, target = to).
   - Return GraphData with auto-generated metadata (generatedAt = now).
3. Otherwise throw: `'Invalid transaction data. The input file must contain a JSON array of transaction objects with \`from\`, \`to\`, and \`value\` fields.'`

**`extractGraphFromCase(caseId: string): Promise<GraphData>`**:
1. Read evidence files from `caseDir(caseId)/evidence/` directory.
2. For each `.md` file: read content, call `parseEvidenceJson(body)` on the body (after frontmatter).
3. Collect all transaction items.
4. If full GraphData objects found in evidence, merge them (combine nodes arrays, combine edges arrays, dedup).
5. Otherwise, treat collected items as simple `{from, to, value}` array and pass to `extractGraphFromJson`.
6. Enrich nodes with entity types from dossiers:
   - Dynamically import DossierStore: `const { DossierStore } = await import('../cases/index.js')`
   - Call `DossierStore.listSummaries(caseId)` to get entity type mappings.
   - For each node, if a dossier exists for that address, set `entityType` from the dossier type.
7. Set metadata: `caseId`, `title: caseId + ' - Money Flow'`, `generatedAt: new Date().toISOString()`.
8. Handle missing evidence directory gracefully (return empty graph, not an error).

Node deduplication: group by `node.id`, merge by summing `totalIn`, `totalOut`, `txCount`, keeping first-seen `firstSeen` and latest `lastSeen`.

Edge aggregation for same source-target pair: sum `value`, increment a virtual count (but keep last txHash/timestamp).

Also export the barrel: `export const DataExtractor = { extractGraphFromCase, extractGraphFromJson, parseEvidenceJson }`.
